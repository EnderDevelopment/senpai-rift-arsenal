# Minecraft Plugin: Senpai Rift Arsenal

Senpai Rift Arsenal is a Minecraft plugin for Paper 1.21.11 that adds custom mace and spear weapons with powerful combat abilities, Elytra momentum, domain effects, custom item data, and Geyser-compatible server-side gameplay.

## Install

1. Use Java 21 or newer.
2. Run a Paper 1.21.11 server.
3. Download or build the plugin JAR.
4. Place the JAR in the server's `plugins` folder.
5. Restart the server.
6. Confirm that `SenpaiArsenal` is enabled.
7. Give yourself permission for `senpaiarsenal.weapons`, or use an operator account.

## Use

1. Join the server with a player account.
2. Run `/weapons` to receive Senpai's Skybreaker Mace and Senpai's Void Spear.
3. Right-click while holding the Skybreaker Mace:
   - While gliding with an Elytra, receive a forward rocket-style momentum boost with firework effects.
   - On the ground, damage the nearest nearby living target, ignite it, launch it slightly, and create a Maledict Domain effect.
4. Right-click while holding the Void Spear:
   - Create a Void Domain centered five blocks in front of you.
   - Pull nearby living targets toward the center and damage them.
5. Wait eight seconds between ability uses. The cooldown applies to each player.
6. Use the weapons in normal combat for additional damage. The mace adds 8 damage, and the spear adds 5 damage to player attacks using the matching weapon.
